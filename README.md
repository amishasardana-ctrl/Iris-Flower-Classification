# Iris-Flower-Classification
Iris Flower Classification is a machine learning project that predicts the species of an iris flower based on its physical measurements.  There are 3 types of iris flowers:           1. Iris Setosa 2. Iris Versicolor 3. Iris Virginica 

2. Technologies Used
- Python — Programming language
- Pandas — Data manipulation
- NumPy — Numerical calculations
- Matplotlib — Data visualization
- Scikit-learn — Machine learning algorithms
